# Java Swing Student Registration

This project is a basic student registration form developed using Java Swing for the Advanced Java Lab.

## Functions

- Accepts student information
- Allows gender selection with radio buttons
- Clears all fields using the Reset button
- Displays submitted information

## Tools Used

- Java
- Swing
- AWT

## Running the Project

1. Open the project in any Java IDE (NetBeans, Eclipse, or IntelliJ IDEA).
2. Compile the source code.
3. Run the main Java file.

## Objective

The main objective of this project is to practice creating graphical user interfaces using Java Swing and handling user interactions through event listeners.
